# Jay Ambe Jyotish — React Static Website

A responsive, single-page React/Vite website for Ashokbhai Acharya / Jay Ambe Jyotish.

## Included
- Responsive modern astrology-themed design
- Supplied profile/business-card image processed into website assets
- Services, pricing and durations
- Gujarati blog content
- Client reviews
- WhatsApp booking CTAs
- Email and location contact section
- Mobile navigation
- Service booking modal
- No backend/database required

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Deploy

The project is a static Vite app and can be deployed to Vercel, Netlify, Cloudflare Pages, GitHub Pages (with suitable Vite configuration), or any static hosting provider.
